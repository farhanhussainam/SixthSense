# Sixth Sense
**Feel what you can't hear, because important sounds shouldn't go unnoticed.**

Sixth Sense is an assistive app created for the Congressional App Challenge. Built with PictoBlox and a machine learning audio classifier, it detects important sounds like fire alarms and doorbells while ignoring background noise, sending visual alerts to a phone app and haptic alerts to a watch extension.
